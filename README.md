# School Management System

A modern web-based school management system designed to simplify academic and administrative operations for schools.

## Overview

The system provides a centralized dashboard where administrators can manage students, teachers, classes, attendance, examinations, fees, learning materials and other daily school operations.

## Key Features

- Student Management
- Teacher & Staff Management
- Classes & Subjects
- Student Attendance
- Homework Management
- Study Materials
- Exams & Results
- Fees Management
- Library Management
- Transport Management
- Dormitory Management
- Notices & Announcements
- Administrative Dashboard
- Role-Based User Access

## Project Goal

The goal was to create a simple, user-friendly platform that reduces manual administrative work and gives schools one centralized system for managing academic activities.

## My Role

Web Application Developer & System Designer

I worked on the system structure, dashboard design, user experience, workflows and implementation of the management modules.
